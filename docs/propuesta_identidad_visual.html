Sala de Operaciones, no Terminal

Tres cosas puntuales que señalaste: el verde saturado no lee como instrumento serio, el banner de demo tapaba el header, y Laboratorio/Análisis se sienten como una terminal — números adentro, texto afuera, sin nada que lo conecte con que hay una simulación corriendo. El banner ya está arreglado. Esto es la propuesta para las otras dos.

01

Color: el verde brillante actual es el mismo registro visual que una pantalla de "hacker" de película — no el de un centro de mando real. Hay una convención real detrás de esto, no es gusto estético: la simbología militar OTAN (APP-6) usa azul para fuerzas propias, rojo para hostil, amarillo para desconocido — el verde queda reservado para neutral. Un panel de operaciones propio en azul, no en verde, es más fiel a esa convención.

02

Laboratorio/Análisis parecen terminal: se aprieta un botón y aparece un bloque de texto. El backend ya calcula una serie de convergencia en cada experimento Monte Carlo (cómo se va afinando la estimación réplica a réplica) — hoy esa serie se descarta y solo se muestra el número final. Graficarla es la diferencia entre "acá está el resultado" y "mirá la simulación pensando".

Paleta propuesta

No es solo "menos verde" — es separar dos cosas que hoy comparten el mismo verde y no deberían: el color de la interfaz (qué está activo, qué se puede tocar) y el color de estado de un dron (activo, dañado, neutralizado). Hoy compiten por el mismo verde. Separados, cada uno se lee más rápido.

Iconografía

El emoji de color (🎲🧬📊) es el mismo lenguaje visual que un chat o una app de consumo — no el de un panel de control. La propuesta: iconos de línea monocromáticos, tinte único (el acento azul), mismo trazo en todos.

Cómo migrar

1
Tokens de color

Reemplazar las variables CSS (--accent-green y compañía) en un solo lugar — todo lo que hoy usa esa variable cambia junto, sin tocar cada componente a mano.

2
Gráfico de convergencia

Usar convergencia (ya viene en la respuesta de /api/experiments) para dibujar la banda de IC angostándose en vivo mientras corre el experimento — no hace falta ningún cambio de backend.

3
Iconos

El más grande de los tres — 20+ lugares usan emoji hoy. Se puede hacer gradual: primero los títulos de sección (más visibles), después los botones.
